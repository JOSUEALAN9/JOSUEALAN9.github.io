Help and support

Your Fiscontable account and Fiscontable Agent, the Windows program that runs on your PC the SAT procedures you request on the web.

The application is in Spanish, since it is built for accounting work in Mexico. The Spanish help page has the full detail.

Your account

I forgot my password

On Sign in, choose ¿Olvidaste tu contraseña? (Forgot your password?) and enter your email. You will receive a link to create a new one; it lasts 2 hours.

I am not getting the verification code

Check your spam folder and wait a minute before requesting another. Each code lasts 10 minutes. If you use an authenticator app, make sure your phone's clock is set automatically.

What is "Trust this device"?

If you tick it when signing in, that browser will not ask for the second step again for 30 days. Use it only on your own computer. You can remove a device under Configuración → Seguridad.

How do I start if I do not have an account yet?

Request a demo. We activate your access and let you know by email.

Fiscontable Agent

While the Agent is running, your account's SAT procedures (tax status certificate, 32-D compliance opinion, returns, tax mailbox review and invoices from the SAT portal) run from your PC, with your internet connection and your browser, and the result appears on the web as usual. It also keeps a copy in Documents\Fiscontable.

You need a Fiscontable account and 64-bit Windows 10 or 11. If your PC is off, procedures run on the server as usual.

Install and connect it

  1. Install it from Microsoft Store (search for "Fiscontable Agente") or with the web installer: menu with your name → Conectar esta PC → Descargar el agente.
  2. Download the installer from the web: menu with your name → Conectar esta PC → Descargar el agente. Coming soon to Microsoft Store.
  3. Open it. The Conectar esta PC (Connect this PC) window appears.
  4. On the web: menu with your name → Conectar esta PC → Pedir código. Type the 8-letter code into the Agent (it lasts 2 minutes) and press Conectar.
  5. On the web, approve the new PC with «Sí, es mi PC». Until then it receives no procedures.
Done: the green icon next to the clock means it is connected. Click the icon → Ver estado to see what it is doing.

The icon next to the clock

  • Green: connected and ready to work.
  • Amber: connected but waiting (PC not approved, paused or outside its schedule).
  • Gray: no connection to the server.

Agent FAQ

Is it safe? What can the Agent see?

Your PC calls the server; nobody connects into your PC and no port is opened. The e.firma arrives only for each procedure and is deleted when it ends. It only reads the tax mailbox: it never opens a pending notification. More detail in the Privacy notice.

Windows or my company's antivirus shows a warning

The Microsoft Store version is signed by Microsoft and is the recommended one for company PCs. With the web installer, Windows may show "Unknown publisher": it is a warning, not an error. The Agent only connects to api.fiscontable.app over HTTPS and to the SAT portals.

Where do documents end up?

On the web, as usual, plus a copy in Documents\Fiscontable\RFC\…, sorted by type. The copy can be turned off from the web.

Stop it from starting with Windows

Windows: Settings → Apps → Startup → turn off Fiscontable Agente. You can open it any time from the Start menu.

Disconnect or uninstall it

Icon menu → Desconectar esta PC, or from the web under Conectar esta PC. To remove it: Settings → Apps → Fiscontable Agente → Uninstall. Your copies in Documents are not deleted.
